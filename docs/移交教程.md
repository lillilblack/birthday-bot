# 移交教程：把机器人交给下一任队长（2026-08-19）

> 适用场景：队长换届，把「生日提醒机器人 + 网页」交给下一任队长，**纯用 GitHub（不涉及国内云服务器）**。以后每届队长照着做即可。

## 0. 先说最关键的

**微信绑定是「一人一 bot」，换不了人、也传不了人。**

- 机器人的微信凭证（`ILINK_TOKEN` / `CONTEXT_TOKEN`）绑定的是**扫码那个人的微信**，别人没法继承，而且 `CONTEXT_TOKEN` 约 24 小时就过期。
- 能通过 GitHub 移交的只有：**代码、名单、工作流、网页、教程**。
- 微信凭证必须**下一任队长本人用自己微信重新扫码绑一个新 bot**——这是移交里唯一「绕不过去、必须他亲手做」的一步。

## 1. 现任队长：把仓库交给他（三选一）

| 方式 | 怎么做 | 网页链接 |
|---|---|---|
| **A. 正式移交仓库** | 仓库 Settings → Danger Zone → Transfer ownership，填他的 GitHub 用户名 | 会变（换成他用户名下的 `xxx.github.io/birthday-bot/`，需同步改文档里的 URL） |
| **B. 让他 fork** | 他 fork 这个仓库，自己跑一份 | 他自己的 fork 是另一个链接 |
| **C. 加协作者（推荐）** | 把他加成 collaborator，仓库仍在你名下 | **不变**（`lillilblack.github.io/birthday-bot/`） |

推荐 **C**（链接不变、最省事）；想「仓库也正式归他」再选 A。

## 2. 下一任队长：四步接手

### 第 1 步：装环境、拉代码

```bash
# 需要 Bun（https://bun.sh）
bun install
```

### 第 2 步：用自己的微信重绑 bot（核心，必须 iOS 微信扫码）

```bash
bun run get-token
```

- 出二维码 → 用 **iOS 微信**扫码确认 → 拿到 `ILINK_TOKEN`
- 微信给 bot 发一句「绑定我」→ 脚本自动拿到 `TO_USER_ID` + `CONTEXT_TOKEN`

> 这步也有网页版向导（`docs/setup.html`），但命令行 `bun run get-token` 最直接。

### 第 3 步：填 4 个 GitHub Secrets

仓库 Settings → Secrets and variables → Actions → New repository secret，依次建：

| Secret 名 | 填什么 |
|---|---|
| `ILINK_TOKEN` | 第 2 步扫码拿到的 |
| `TO_USER_ID` | 第 2 步发「绑定我」拿到的 |
| `CONTEXT_TOKEN` | 第 2 步发「绑定我」拿到的 |
| `BIRTHDAYS_JSON` | 整段名单 JSON，直接拷 `docs/roster.json` 的内容（当前 58 人） |

> ⚠️ 如果是 **fork** 的仓库，先到 Settings → Actions → 允许 Actions 运行，否则工作流不触发。

### 第 4 步：验证 + 开网页

1. Actions 标签页 → 选 `Birthday Bot` → Run workflow（手动触发一次），确认能发出提醒。
2. 开 GitHub Pages：Settings → Pages → Source 选「Deploy from a branch」→ `main` + `/docs` → Save，约 1 分钟出现绿框。
3. 把网页链接发队群。

## 3. 只用 GitHub（不用国内云）的代价

1. **回消息慢**：`check.yml` 每 30 分钟轮询一次，加上 GitHub 国外服务器连微信 iLink 经常超时，实测「查生日」可能要等半小时到一小时。**每日 00:00 提醒是定时触发、不受影响**；慢的只是查询。
   - 想快一点：把 `check.yml` 的 `*/30` 改成 `*/15`（公开仓库 Actions 分钟免费不限量）；但 iLink 国外超时根治不了，**要秒回只有国内云**。
2. **token 要续命**：`CONTEXT_TOKEN` 约 24h 过期，新队长每隔一两天给 bot 发句话续命（bot 会发提醒）。
3. **微信自助增改不跨人**：自助增改的成员存在 Actions Cache（`.runtime/`）里，换人不带；名单以 `BIRTHDAYS_JSON` Secret 为准。

## 4. 常见问题

- **下一任队长没有 iOS 设备 / 微信扫不了码？** 扫码这步官方要求 iOS 微信（脚本里也是这么写的），这是 iLink 平台的限制，不是本项目问题。
- **网页打不开？** 先确认 Pages 已开且选的是 `/docs`；再考虑国内访问 GitHub Pages 时快时慢的网络问题（和 Actions 连微信慢同源）。
