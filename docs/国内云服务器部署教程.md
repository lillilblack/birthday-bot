# 生日机器人 · 国内云服务器部署教程（真正彻底不要电脑）

> 为什么不用 GitHub 免费云端？因为微信的 iLink 接口（`ilinkai.weixin.qq.com`）**只认国内 IP**，GitHub 的服务器全在国外，连不上——云端能跑但一调微信接口就超时。所以要做到「电脑关机也照常回消息」，唯一的办法是租一台**国内地域**的服务器，把机器人常驻跑在上面。

---

## 0. 先搞懂原理（30 秒）

**服务器上跑一个「永远不关」的进程**，每 2 秒轮询一次微信新消息、秒回；再用系统自带的两条「定时任务」补齐每日提醒和续命提醒：

| 任务 | 频率 | 对应命令 |
|---|---|---|
| 回微信消息（常驻） | 每 2 秒 | `bun run listen` |
| 发每日生日提醒 | 每天 00:00 | `bun run start` |
| 提醒你「续命」 | 每 6 小时 | `bun run check-expiry` |

服务器 24 小时开机，跟你的电脑毫无关系了。

选 **腾讯云** 或 **阿里云** 的「**轻量应用服务器**」，这是最便宜、最适合小机器人的款式。

2. 领取「轻量应用服务器」免费试用：一般 **1~3 个月**（部分活动到 6 个月），配置约 2 核 2G / 2 核 4G。
3. 试用到期后走「云翼计划」学生机续费，约 **9.9 元/月**（一年 ~100 元）。

**腾讯云 · 云+校园**
1. 搜索「腾讯云 云+校园」，25 岁以下（全日制在校生）完成学生认证。
2. 领取轻量应用服务器免费套餐，一般 **1~3 个月**。

> - 两家都要求**实名认证 + 学生认证**。「新用户免费试用」每个账号**只有一次**，别浪费在别的产品上。

### 1.2 关键配置，照着选

| 项目 | 怎么选 |
|---|---|
| 地域 | **必须选国内**：上海 / 广州 / 北京都行（这是本方案成立的前提） |
| 系统镜像 | **Ubuntu 22.04** 或 **24.04**（选 Ubuntu 就好，教程按它写） |

> 别选「Windows Server」，选 Linux Ubuntu；也别选香港/海外地域，那又变回国外 IP 了。

## 2. 连接服务器

买好后，在你电脑上打开 **cmd**（`Win + R` 输入 `cmd`），用 ssh 连上去。把下面命令里的 `你的IP` 换成你的公网 IP：

```bat
ssh root@你的IP
```

第一次连接会问 `Are you sure you want to continue connecting`，输入 `yes` 回车。然后输入密码（输入时屏幕不显示，正常，输完回车）。

看到提示符变成 `root@xxx:~#` 就说明连上了。

---

## 3. 装 Bun（机器人的运行环境）

连上服务器后，逐行复制粘贴下面命令：

```bash
curl -fsSL https://bun.sh/install | bash
```

装完后让环境变量生效，并确认能查到路径：

```bash
source ~/.bashrc
which bun
```

最后一行应该输出类似 `/root/.bun/bin/bun` 的路径。**记下这个路径**，后面要用到。如果输出为空，重开一次 ssh 连接再 `which bun`。

---

## 4. 把代码传到服务器

代码已经在你的 GitHub 私有仓库里了，在服务器上直接拉下来最省事。

### 4.1 生成一个 PAT（个人访问令牌）

1. GitHub 右上角头像 → **Settings** → 左侧最下面 **Developer settings** → **Personal access tokens** → **Tokens (classic)**。
2. **Generate new token (classic)** → Note 随便填（如 `server`）→ 勾选 **repo** → 拉到最下 **Generate token**。
3. 复制那串 `ghp_...`（只显示一次）。

### 4.2 在服务器上拉代码

在服务器上执行（把 `你的PAT` 换成刚复制的那串，`lillilblack` 是你的用户名）：

```bash
git clone https://lillilblack:你的PAT@github.com/lillilblack/birthday-bot.git
```

> 注意：地址里 `lillilblack:你的PAT@` 中间是冒号不是空格。这一步可能会有点慢（国内连 GitHub），耐心等，看到 `done` 就行。

成功后服务器上会多一个 `birthday-bot` 文件夹，进入它：

```bash
cd birthday-bot
```

> **备选上传方式**：如果 git clone 一直卡住，也可以不用 GitHub——在你**本机**用 FileZilla（图形化工具）或 `scp` 把项目文件夹（排除 `.git`、`node_modules`）整个传上去。传完告诉我，我给你对应的命令。

## 5. 配置密钥和名单

在服务器上，进入 `birthday-bot` 目录后，创建 `.env` 文件：

```bash
nano .env
```

粘贴下面内容（**把 `<...>` 换成你本机 `.env` 里对应的值**）：

```
ILINK_TOKEN=<ILINK_TOKEN 的值>
TO_USER_ID=<TO_USER_ID 的值>
CONTEXT_TOKEN=<CONTEXT_TOKEN 的值>
```

> 本机 `.env` 在 `e:\大学\大学生活\辩论队\birthday-bot-master\.env`，用记事本打开复制。三个值分别是 `ILINK_TOKEN=`、`TO_USER_ID=`、`CONTEXT_TOKEN=` 后面的整串。

粘贴后按 **Ctrl+O** 回车保存，再 **Ctrl+X** 退出。

接着放名单文件 `birthdays.json`。同样在 `birthday-bot` 目录下：

```bash
nano birthdays.json
```

把你本机 `birthdays.json` 的**整个内容**粘贴进去，`Ctrl+O` 保存、`Ctrl+X` 退出。

> 名单也可以之后用微信自助增改（给机器人发「添加生日 王小明 阳历 3 月 15 日」），不一定要在这里改。

## 6. 安装依赖 + 试跑一次

在 `birthday-bot` 目录下：

```bash
bun install
```

装完先手动跑一次「回消息」，验证能连上微信接口（这是本方案的关键验证）：

```bash
bun run check
```

- 如果输出类似 `检查完成：收到 0 条消息，回复 0 条` → **接口连通成功**，继续下一步。
- 如果输出 `getupdates 失败或超时` → 说明服务器还是连不上微信接口，把输出发我。

## 7. 让机器人常驻运行（关键步骤）

### 7.1 创建系统服务文件

```bash
nano /etc/systemd/system/birthday-bot.service
```

粘贴下面内容（**把两处 `/root/.bun/bin/bun` 换成第 3 步 `which bun` 输出的路径**；如果 `cd` 到的目录不是 `/root/birthday-bot` 也改一下）：

```ini
[Unit]
Description=Birthday Bot (WeChat)
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
WorkingDirectory=/root/birthday-bot
ExecStart=/root/.bun/bin/bun run listen
Restart=always
RestartSec=5
EnvironmentFile=/root/birthday-bot/.env

[Install]
WantedBy=multi-user.target
```

`Ctrl+O` 保存、`Ctrl+X` 退出。

### 7.2 启动并设为开机自启

```bash
systemctl daemon-reload
systemctl enable --now birthday-bot
```

### 7.3 看它有没有在跑

```bash
systemctl status birthday-bot
```

看到绿色的 `active (running)` 就成功了。如果红色 `failed`，执行 `journalctl -u birthday-bot -n 50` 看报错，把结果发我。

---

## 8. 配置两条定时任务（每日提醒 + 续命）

创建一个脚本，让定时任务能读到密钥：

```bash
nano /root/birthday-bot/run-cron.sh
```

粘贴（把 `/root/.bun/bin/bun` 换成你的 bun 路径）：

```bash
#!/bin/bash
cd /root/birthday-bot
set -a
source .env
set +a
/root/.bun/bin/bun run "$1"
```

保存退出后，给它执行权限：

```bash
chmod +x /root/birthday-bot/run-cron.sh
```

编辑系统定时任务：

```bash
crontab -e
```

（第一次会问用哪个编辑器，选 `nano`。）在文件末尾加这两行（同样改 bun 路径）：

```
0 0 * * * /root/birthday-bot/run-cron.sh start >> /root/birthday-bot/logs/cron.log 2>&1
0 */6 * * * /root/birthday-bot/run-cron.sh check-expiry >> /root/birthday-bot/logs/cron.log 2>&1
```

`Ctrl+O` 保存、`Ctrl+X` 退出。

## 9. 最终测试

1. 用绑定的微信给机器人发一句 **「你好」**。
2. 机器人应该**几秒内就回**（服务器 2 秒轮询，比之前的 5 分钟快得多）。
3. 再试试 `今天谁生日`、`添加生日 王小明 阳历 3 月 15 日` 等指令，都正常就大功告成。

现在可以**彻底关机、断网、笔记本合盖**，机器人都在服务器上自己跑。

---

## 10. 日常维护

- **改名单**：直接用微信发「添加生日 / 修改生日」最方便，无需碰服务器。
- **看运行状态**：连上服务器 `systemctl status birthday-bot`；看日志 `journalctl -u birthday-bot -f`（实时滚动，`Ctrl+C` 退出）。
- **续命**：每隔一两天给机器人随便发一句，token 就不会过期。
- **改代码后更新服务器**：连上服务器进 `birthday-bot` 目录执行 `git pull`，再 `systemctl restart birthday-bot`。
- **服务器到期**：记得续费，否则机器人就停了。

## 常见问题

**Q：`which bun` 没输出？**
重新 `source ~/.bashrc`，或退出 ssh 重连一次再试。

**Q：`bun run check` 报 `getupdates 失败或超时`？**
说明服务器还是连不上微信接口，通常是地域选错了（选了香港/海外）。把地域改回国内，或把报错发我。

**Q：`systemctl status` 显示 failed？**
执行 `journalctl -u birthday-bot -n 50` 看红色报错，发我。最常见是 bun 路径填错、或 `.env` 没建对。

**Q：token 过期了怎么办？**
服务器常驻 + 每 6 小时续命提醒，正常情况下你只要隔一两天回机器人一句就不会断。断了的话，重新发一条消息给机器人即可恢复。
